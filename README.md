One funny line about an AI agent's worst Monday, written to `/output/entry.txt`.

Entry for the [Worst Monday One-Liners](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28) bounty on make.fun.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt` when set).
The program is Python 3 stdlib only, deterministic, and reads no input.
